# Plot Studio backup — 2026-09-01

This is a pre-publication-upgrade snapshot of the R-Plot Studio UI and plot state service.

To restore the prior implementation, replace the corresponding files in
`frontend/src/app/tools/plot-studio/` and
`frontend/src/app/services/r-plot-sync.service.ts` with this snapshot, then run
the frontend test suite.

The Git commit containing this upgrade is an additional rollback point.
